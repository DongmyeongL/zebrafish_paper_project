# Figure 14 C. elegans Final Files

Final analysis choice:

- Final combined figure PNG: `figures/figure14_celegans_full_combined_FINAL.png`
- Activity metric: spontaneous `FCV_z`
- Window: `w60`, 60 frames, approximately 36.1 s
- Filter: exclude neurons with `abs(PostDCA) <= 1e-12`
- Matrix figure set: `n_recordings >= 3`, spontaneous phase
- Cluster method: Sohn et al. 2011-inspired directed weighted modularity, `k = 5`
- Structural-out FCV and old FCD outputs are excluded from this folder.
- New PDF outputs are not generated by the current final scripts; PNG is the
  active figure format.
- Legacy intermediate figures/results/matrices were removed after finalization.
  The remaining files are the final figure, final SC/FC heatmaps, current
  result tables, and the `nrec3_spontaneous` matrix inputs needed by the final
  combined figure.

## Current SC Measure Heatmap

- Final SC measure calculation uses the full 297-neuron C. elegans directed
  chemical synapse matrix, removes the diagonal, computes the four SC measures,
  and then subsets to the 122 neurons in the SC/FC common set.
- Measures: `PostDCA`, `PreDCA`, `Log10_OutInput_degree`, and
  `OO_fraction`.
- Final table:
  `results/figure14_celegans_sc_cell_measures_full297_subset122.csv`
- Final figure:
  `figures/figure14_celegans_sc_cell_measure_heatmap_full297_subset122.png`
- Method record:
  `SC_MEASURE_HEATMAP_METHOD.md`

## Current FC Measure Heatmap

- FC measures are computed from spontaneous sections only.
- Basic measures (`z-FCS`, `z-FCV`, metastability) and TE measures (`Net TE`,
  `Neighbor Net TE`) are computed in separate scripts and combined afterward.
- Main TE setting: 4 quantile bins, lag 1 frame.
- Final neuron-level table:
  `results/figure14_celegans_fc_spontaneous_5measure_summary.csv`
- Final figure:
  `figures/figure14_celegans_fc_cell_measure_heatmap.png`
- The FC heatmap uses Ward hierarchical clustering and mirrors dendrogram
  branches so high-`FCV_z` neurons are placed as far left as possible.
- Method record:
  `FC_MEASURE_HEATMAP_METHOD.md`

## Current Full Combined Figure

- Script:
  `code/figure14_celegans_full_combined_FINAL.py`
- Output:
  `figures/figure14_celegans_full_combined_FINAL.png`
- Panels I and J read `FCV_z` directly from the current spontaneous FC analysis:
  `results/figure14_celegans_fc_spontaneous_5measure_summary.csv` and
  `results/figure14_celegans_fc_spontaneous_basic_recording_level.csv`.
- The updated FCV values match the older full-combined FCV values numerically
  (`r=1.0`, mean absolute difference \(4.7\times10^{-17}\)).

## Current Neuron Counts

- The spontaneous activity label cache contains 148 cleaned neuron labels across
  the 18 spontaneous recordings used for FCV analysis.
- The `nrec3_spontaneous` matrix/order files start from 122 SC/activity matched
  candidate neurons with non-zero Post-DCA and at least 3 recordings in the
  matrix-generation summary.
- The current spontaneous FCV summary contains 120 neurons with computable
  `FCV_z`. `ASHR` and `BAGR` are present in the 122-neuron matrix order but have
  no valid spontaneous FCV pairs in the final FCV matrix.
- In the current spontaneous recording-level FCV table, 113 of the 120 neurons
  are observed in at least 3 actual spontaneous recordings. The 7 neurons with
  fewer than 3 actual spontaneous recordings are `ADAR`, `ALA`, `AVBR`, `AVKL`,
  `AVKR`, `SMBVR`, and `URAVR`.

Count lineage:

-> 120 neurons with computable spontaneous FCV_z
